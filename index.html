ตั้งค่าครั้งเดียว เพื่อให้หน้าเว็บซิงค์ข้อมูลกลับเข้าไฟล์ Google Sheet ได้โดยตรง
ขั้นตอนติดตั้ง Apps Script (ทำครั้งเดียวประมาณ 1 นาที):
  1. เปิดไฟล์ Google Sheet (PM Plan) → เมนูด้านบน ส่วนขยาย (Extensions) → Apps Script
  2. ลบโค้ดเดิมใน Code.gs ออก แล้วกดปุ่ม "คัดลอกโค้ด Code.gs" ด้านล่างไปวางแทนที่ แล้วกดบันทึก (Ctrl + S)
  3. กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)
  4. เลือกประเภท เว็บแอป (Web app) ตั้งค่า:
    • ดำเนินการในฐานะ (Execute as): ฉัน (Me)
    • ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)
  5. กด Deploy → อนุญาตสิทธิ์ → คัดลอก URL ของเว็บแอป (ลงท้ายด้วย /exec) มาวางในช่องด้านบน
